# AroNexa Healthcare Platform

AroNexa is a planned configurable clinic, hospital and specialty healthcare platform.

## Project status

Phase 00: architecture and requirements planning. No application implementation has been approved or committed.

## Delivery rules

- Java 21, Spring Boot, Spring Modulith, React, TypeScript, PostgreSQL and Flyway are proposed.
- Clinical safety, auditability, tenant isolation and accessible workflow-first UI are required.
- Never copy or depend on CareNexus code.
- No merges, deployments, destructive migrations or advancement to the next phase without explicit owner approval.
- Phase 00 documents are developed on a separate review branch and must be reconciled with the definitive Phase 00–14 requirements before approval.
